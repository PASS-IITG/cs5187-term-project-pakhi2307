\section{Data Availability}
\label{sec:data}

The source code, graph databases, evaluation harness, raw result JSONL files,
and analysis scripts are available in the anonymous supplementary repository.
The repository includes build instructions for the call-graph databases from
the \sqlite~3.30.1 source tree, one-command reproduction of the headline
result, and pre-computed result files for both models.
No upstream bug reports or patches were filed against \sqlite{} as part of this
work.
